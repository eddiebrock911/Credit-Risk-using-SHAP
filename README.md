# 💳 Credit Risk Analysis using SHAP

<p align="center">
  <strong>Machine Learning • Explainable AI • Financial Risk Analytics</strong>
</p>

An Explainable AI project focused on understanding credit risk predictions and identifying the factors influencing a Machine Learning model's decisions using **SHAP (SHapley Additive exPlanations)**.

## ✨ Key Features

- 💳 Credit risk prediction
- 🤖 Machine Learning-based analysis
- 🔍 SHAP model explainability
- 📊 Feature importance analysis
- 🧠 Interpretable predictions
- 📈 Data-driven risk assessment

## 🛠️ Tech Stack

- Python
- Pandas & NumPy
- Scikit-learn
- SHAP
- Matplotlib

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/eddiebrock911/Credit-Risk-using-SHAP.git
cd Credit-Risk-using-SHAP
```

Install dependencies if `requirements.txt` is available:

```bash
pip install -r requirements.txt
```

Open the project's notebook or Python script and run the workflow according to the files in the repository.

## 🎯 Project Goal

Demonstrate how Explainable AI can make Machine Learning-based credit risk predictions easier to interpret by showing which features contribute to model outputs.

## ⚠️ Disclaimer

This project is for educational and analytical purposes. Model predictions should not be used as the sole basis for real-world lending decisions.
